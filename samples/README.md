# Specimen documents (fictional)

Every file in this folder is **made up** for the DocuFlow demo. The people, numbers and dates are not real. Each one is marked **SPECIMEN**.

| File | What it is | Use it to show |
|---|---|---|
| `specimen-passport-olena.svg` | Passport for Olena Kovalenko (same name and date of birth as worker w-001, new passport number) | Worker upload: all fields High. Recruiter upload: attaches to Olena and flags the new passport number |
| `specimen-passport-new-worker.svg` | Passport for Tetiana Moroz, who is not in the demo data. The expiry check digit is wrong on purpose | Recruiter upload: creates "New – needs review" worker. Expiry shows Low |
| `specimen-forklift-licence-olena.pdf` | Forklift operator licence (PDF) for Olena Kovalenko | PDF reading, pattern-matched licence fields, Low category that needs "It's correct" |

In the app, use the "Try a specimen" links (worker: My documents; recruiter: Documents → Upload a document). The SVGs are drawn to a PNG in the browser before reading.
